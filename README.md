## 🌌 What is Cosmic Birthday Voyage?

**Cosmic Birthday Voyage** is an immersive, interactive web experience that takes you on a journey through space history — anchored to *your* birthday. Enter your birth date and explore a beautifully animated timeline of real cosmic milestones, discoveries, and missions that share a connection to your moment in time.

Built as a submission for **AstroHack 2025**, this project combines astronomy, history, and interactive storytelling into a single, seamless experience.

---

## ✨ Features

- 🎂 **Birthday-Powered Timeline** — Enter your birthdate and get a personalized cosmic history experience
- 🌠 **Interactive Space History** — Explore real astronomical events, missions, and discoveries
- 🌌 **Immersive UI** — Stunning space-themed visuals with smooth animations and particle effects
- 📱 **Fully Responsive** — Works beautifully across desktop, tablet, and mobile
- ⚡ **Blazing Fast** — Built with Vite for near-instant load times
- 🎨 **Animated Storytelling** — Events revealed through cinematic, scroll-driven interactions

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- [Bun](https://bun.sh/) (recommended) or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/srijavuppala/cosmic-birthday-voyage.git
cd cosmic-birthday-voyage

# Install dependencies
bun install

# Start the development server
bun run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
bun run build
bun run preview
```
